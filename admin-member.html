Panduan Langkah Demi Langkah: Cara Memeriksa Langsung Database di Konsol Cloud

Selain menggunakan dashboard lokal ini, Anda dapat memeriksa, memantau, dan mengedit data konsumen secara langsung di portal resmi Cloud Database kapan saja dengan langkah berikut:

1
Buka Dashboard Cloud Database
Akses peramban web dan kunjungi alamat dashboard database cloud Anda. Masuk dengan akun yang Anda gunakan saat membuat proyek.
2
Pilih Proyek Duta GeoSpasi
Di daftar project, klik nama proyek Anda: vezruyffzmabhtylxigc (atau nama proyek geospasial Anda).
3
Buka Menu "Table Editor"
Di bilah menu sebelah kiri (sidebar vertikal), cari icon berupa kotak tabel bernama Table Editor. Klik menu tersebut untuk membuka daftar tabel basis data Anda.
4
Melihat Daftar Member Konsumen pada Tabel "members"
Klik tabel bernama members di bawah skema public. Di sini Anda akan melihat:
• email: Alamat email konsumen yang pernah mendaftar.
• role: Hak akses akun (isi nilainya: pro atau free).
• status: Status akun (biasanya active).
Tips Pro: Anda bisa mengklik ganda (double-click) sel kolom role langsung di tabel untuk mengubahnya dari "free" menjadi "pro", lalu tekan tombol Save.
5
Melihat Mutasi Kode Unik QRIS pada Tabel "payments"
Klik tabel payments. Setiap kali konsumen membuka pop-up QRIS, sistem otomatis mencatat:
• unique_code: 3 digit kode unik acak (misal 428).
• total_amount: Total nominal yang ditransfer (misal Rp 75.428).
• status: Berstatus "pending" sampai Anda atau sistem menyetujuinya menjadi "approved".
6
Memeriksa Akun Terdaftar di Menu "Authentication"
Jika Anda ingin melihat akun yang login menggunakan Google OAuth atau Email OTP, klik icon gembok di menu kiri bernama Authentication > Users. Anda dapat melihat daftar User UID dan status verifikasi email mereka.
7
Kunci Keamanan RLS & Hak Akses Penuh Kontrol Admin
Untuk mengamankan database dari manipulasi publik, Row Level Security (RLS) pada tabel members dan payments wajib aktif.
Agar Dashboard Admin ini memiliki hak akses penuh (bisa edit status PRO, blokir akun, atau hapus sampah transaksi):
1. Buka Project Settings > API di Supabase.
2. Salin service_role (secret) key.
3. Klik tombol Konfigurasi API di kanan atas dashboard ini, tempelkan Service Role Key lalu simpan.
