Konfigurasi Gateway & Proxy Geospasial

Duta GeoSpasi beroperasi secara online dengan integrasi aman Supabase Edge Gateway dan basis data geospasial resmi.

Data bidang tanah kadaster diproses melalui koneksi HTTPS berkecepatan tinggi dengan validasi resmi ATR/BPN Republik Indonesia.
Pilihan Server Kadaster:
Server 2 mengambil data langsung dari BPN dan diproses di peramban tanpa perantara server Supabase (khusus Member PRO).
Keamanan Otentikasi Google:
Sistem otentikasi Google OAuth dikunci secara ketat untuk domain resmi https://geospasi.dutamik.id.
Gateway Proxy Geospasial Kustom (Opsional):
Bila ingin menghubungkan server proxy mandiri berkecepatan tinggi, masukkan URL proxy HTTPS resmi (contoh: https://proxy.domainanda.com). Tanpa gateway, sistem otomatis menggunakan gateway default resmi.

VEKTOR CAD (.DXF)
AutoCAD DXF (.dxf)
Format vektor gambar CAD Drawing Interchange Format (.dxf) standar UTM WGS 84. Menyertakan poligon batas tertutup (layer BATAS_BIDANG), titik patok batas (layer PATOK_BATAS), teks label patok P1..Pn, dan teks luas centroid bidang.
Format Data:AC1009 ASCII DXF (Layers: Batas, Patok, Teks)
Kompatibilitas:AutoCAD, Civil 3D, QGIS, ArcGIS
SCRIPT CAD (.SCR) & KOORDINAT
AutoCAD Script (.scr) & Koordinat
Script otomatis (.SCR) gambar bidang tanah langsung di AutoCAD. Tersedia Opsi 1 skala 1cm : 100cm (origin lokal 0,0) dan Opsi 2 koordinat asli sistem SHP (UTM WGS 84).
