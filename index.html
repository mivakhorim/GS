PILIH FORMAT EKSPOR KOORDINAT
Pilih sistem proyeksi koordinat sesuai kebutuhan peta atau CAD
VEKTOR CAD (.DXF)
AutoCAD DXF (.dxf)
Format vektor gambar CAD Drawing Interchange Format (.dxf) standar UTM WGS 84. Menyertakan poligon batas tertutup (layer BATAS_BIDANG), titik patok batas (layer PATOK_BATAS), teks label patok P1..Pn, dan teks luas centroid bidang.
Format Data:AC1009 ASCII DXF (Layers: Batas, Patok, Teks)
Kompatibilitas:AutoCAD, Civil 3D, QGIS, ArcGIS
SCRIPT CAD (.SCR) & KOORDINAT
AutoCAD Script (.scr) & Koordinat
Script otomatis (.SCR) gambar bidang tanah langsung di AutoCAD. Tersedia Opsi 1 skala 1cm : 100cm (origin lokal 0,0) dan Opsi 2 koordinat asli sistem SHP (UTM WGS 84).
Opsi 1 (Skala):1cm : 100cm (Origin Lokal 0,0)
Opsi 2 (Georeferensi):Koordinat Sistem SHP (UTM WGS 84)
OPSI 1: SKALA 1cm : 100cm Origin Lokal (0,0)
OPSI 2: KOORDINAT SISTEM SHP UTM WGS 84
VEKTOR SVG PRESISI
Gambar SVG Persil Bidang Tanah
Gambar vektor presisi format SVG berstandar kadastral. Menyertakan poligon bidang tanah, titik patok batas berlabel, jarak antar patok (meter), koordinat UTM setiap patok, arah utara, skala bar, grid UTM, tabel koordinat, dan informasi persil lengkap (NIB, luas, keliling, zona UTM, hak tanah).
Format:SVG (Scalable Vector Graphics) A4 Landscape
Isi Gambar:Poligon, Patok, Jarak, Koordinat UTM, Skala, Legenda, Title Block
Kompatibilitas:Browser, Inkscape, Illustrator, CorelDRAW, AutoCAD (Import SVG), QGIS
DYNAMIC ARCGIS MAP
